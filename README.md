# 🧮 Calc Price to Public

Calculadora de precios para el público a partir de los precios de hasta **5 proveedores**, incluyendo IVA y margen de ganancia.

![preview](./screenshot.png) <!-- Puedes cambiar o eliminar esta línea si no tienes captura aún -->

---

## 🛠️ Tecnologías utilizadas

- **HTML5** – estructura semántica del sitio
- **CSS3** – estilos modernos y responsivos
- **JavaScript** – lógica para cálculos dinámicos

---

## ✨ Características

- Ingreso de precios desde hasta **5 proveedores**
- Personalización de:
  - Porcentaje de **IVA**
  - Porcentaje de **ganancia**
- Cálculo automático del **precio de venta al público**
- Interfaz limpia y fácil de usar
- Responsive: se adapta a dispositivos móviles y escritorio
